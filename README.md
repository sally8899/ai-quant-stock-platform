# AI智能量化选股平台（A股）V1.0

## 1. 当前版本包含
- Streamlit网页操作界面
- AKShare公开行情数据接入（无需单独购买API Key）
- A股基础过滤（ST、价格、成交额等）
- 均线、MACD、RSI、成交量分析
- 潜伏型、突破型、回踩型策略标签
- 量化评分与风险否决
- CSV导出
- 简易均线策略历史回测
- 演示数据模式（明确标记为模拟数据）

## 2. 安装方式
建议使用 Windows 10/11 或 macOS，安装 Python 3.10–3.12。

在项目文件夹打开终端，执行：

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

macOS:
```bash
source .venv/bin/activate
```

安装依赖：
```bash
pip install -r requirements.txt
```

启动：
```bash
streamlit run app.py
```

浏览器打开终端显示的本地地址，通常为 http://localhost:8501 。

## 3. 数据说明
默认使用 AKShare 获取公开A股行情。免费数据源可能出现延迟、限流、字段变化或临时不可用。
如接口失败，可切换演示数据检查界面。演示数据是合成数据，不是真实股票行情，不得用于交易判断。

## 4. 重要限制
本版本是研究原型，不是已验证的盈利系统：
- 暂未接入可靠的实时逐笔行情、Level-2、完整财务/公告/行业资金数据。
- 基本面和行业因子未获得可靠数据前不计分；当前评分是技术与流动性子评分，最高封顶58分。
- 因此默认70分筛选不会产生候选股；请先调低门槛检查流程，不应把低分解释为股票差。
- 买入区间和止损为技术观察参考，不是交易指令。
- 回测是简化模型，尚未完整模拟佣金、印花税、滑点、涨跌停无法成交、停牌及复权细节。
- 不自动下单，不连接券商账户。
